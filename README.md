# MimiTap

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-online-7C3AED)](https://w1zzyakik.github.io/MimiTap/)
[![Release](https://img.shields.io/github/v/release/w1zzyakik/MimiTap)](https://github.com/w1zzyakik/MimiTap/releases/latest)

**Твой клик — её нажатие.** Оверлей-персонаж поверх всех окон: в покое Мими
замахивается (`1.png`), а пока зажата левая кнопка мыши — жмёт кнопку (`2.png`);
отпустили — снова замах. При нажатии проигрывается звук (длительность автоматически
обрезается до 1 секунды). Размер, положение, поведение и звук настраиваются в окне настроек.

Проект сделан по персонажу **Мими** — OC художницы **Typh**: антропоморфная собачка
(страница персонажа: <https://animation-meme.fandom.com/wiki/Typh/Mimi>).
Все картинки приложения — арты Мими.

## Скачать

Готовый установщик: **[MimiTapSetup.exe — последний релиз](https://github.com/w1zzyakik/MimiTap/releases/latest)**
(текущая версия — [`v1.0.0`](https://github.com/w1zzyakik/MimiTap/releases/tag/v1.0.0)).

Нужен **.NET 10 Desktop Runtime** (<https://dotnet.microsoft.com/download/dotnet/10.0>).
Установка без прав администратора, в `%LocalAppData%\Programs\MimiTap`.

## Что умеет

- Прозрачное окно поверх всех окон (Topmost), не забирает фокус у других программ.
- Две картинки: `1.png` (Мими замахивается) и `2.png` (Мими нажала, пока кнопка зажата). Режимы:
  - **Держать 2.png** (по умолчанию) — 2.png показывается с нажатия и держится, пока
    зажата ЛКМ, сразу возвращается 1.png при отпускании, независимо от времени удержания;
  - **По времени** — 2.png показывается N мс после отпускания, затем возвращается 1.png;
  - **Переключать** — каждый клик переключает 1.png ⇄ 2.png.
  - Страховка: если событие отпускания потерялось, 2.png всё равно вернётся в 1.png
    (проверяется реальное состояние кнопки мыши).
- Звук нажатия: wav / mp3 / m4a / wma / aac, громкость, кнопка «Тест»,
  длительность ограничена 1 секундой (ползунок 0.1–1.0 с, длинные файлы обрезаются).
- Размер: свои ширина/высота в пикселях или «размер как у изображения», 5 режимов масштабирования.
- Положение: экран (основной / рабочий стол / под курсором) и привязка из 9 вариантов,
  либо свободное положение с сохранением X/Y, перетаскивание мышью.
- Пропускание кликов: картинка не перехватывает клики, а отслеживает их глобальным хуком
  (нужно, когда клик должен уходить в игру/программу под картинкой).
- Область срабатывания нажатия настраивается:
  - **Весь экран** (по умолчанию) — 2.png показывается при нажатии ЛКМ в любом месте:
    в игре, в браузере, в любой программе;
  - **Весь квадрат окна картинки** — нажатие засчитывается в прямоугольнике картинки;
  - **Только непрозрачные пиксели картинки** — учитывается альфа-канал (маска 256 px);
  - **Запас вокруг** (0–200 px, по умолчанию 40) — зона расширяется за пределы картинки,
    поэтому нажатие по «воздуху» рядом с картинкой тоже её переключает. Текущие границы зоны
    показаны прямо в настройках.
- В режимах «весь экран» / «по времени» / «переключать» нажатие засчитывается, только если
  мышь почти не двигалась между нажатием и отпусканием (порог 12 px) — перетаскивание мышью
  в игре не считается нажатием. В режиме «держать 2.png» 2.png показывается сразу на нажатии,
  даже если мышь сразу поехала.
- Пока открыто окно настроек, нажатие засчитывается только по картинке, иначе каждый клик по
  ползункам переключал бы картинку и играл звук.
- Время удержания замеряется и пишется в журнал (`--diag`): `held=422ms`.
- Перетаскивание картинки мышью работает только если нажатие попало на картинку.
- Хук мыши можно отключить, тогда же отключается и перетаскивание мышью.
- Перетаскивание сглаженное: события мыши объединяются и применяются 60 раз в секунду.
- Трей: показать/скрыть, показать 1.png или 2.png, настройки, выход.
- Окно настроек закрывается в трей, а не завершает программу (крестик, «Свернуть», Alt+F4).
  Выход — только «Выход» в трею или кнопка «Выход» в окне настроек.
- Горячая клавиша (по умолчанию Ctrl+Alt+M) — показать/скрыть картинку.
- Автозапуск с Windows, предпросмотр, сброс настроек.

## Где лежат файлы

| Что | Путь |
|---|---|
| Настройки | `%AppData%\MimiTap\settings.json` (UTF-8 с BOM) |
| Картинки и иконка (можно заменять своими) | `%AppData%\MimiTap\assets\1.png`, `2.png` |
| Лог необработанных ошибок | `%AppData%\MimiTap\error.log` |
| Отчёт самопроверки | `%AppData%\MimiTap\selftest.log` |
| Журнал кликов (`--diag`) | `%AppData%\MimiTap\diag.log` |

## Сборка

```powershell
# обычная сборка
dotnet build .\MimiTap.csproj -c Release

# один .exe + .pdb (нужен .NET 10 Desktop Runtime)
dotnet publish .\MimiTap.csproj -c Release -r win-x64 --self-contained false `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\publish
```

Готовый бинарник: `publish\MimiTap.exe`.

## Установщик

Готовый установщик: `dist\MimiTapSetup.exe` — это **собственный WPF-установщик**
(`installer\MimiTapSetup`), а не Inno Setup, поэтому ничего дополнительно ставить не нужно.
Что делает:

- ставит программу в `%LocalAppData%\Programs\MimiTap` без запроса прав администратора;
- ярлыки: меню «Пуск → MimiTap», «Настройки MimiTap», «Удалить MimiTap»
  (плюс значок на рабочем столе по желанию при установке);
- опции при установке: значок на рабочем столе, автозапуск с Windows (по умолчанию),
  запуск программы после установки;
- регистрирует программу в «Программы и удаление» (`...\Uninstall\MimiTap`);
- полноценное удаление: `Пуск → MimiTap → Удалить MimiTap`; ярлыки и запись автозапуска
  снимаются. По желанию удаляются настройки и картинки (`%AppData%\MimiTap`).

Сборка установщика: он встраивает уже готовый `publish\MimiTap.exe`, поэтому сначала
нужен `dotnet publish` (см. выше), а затем:

```powershell
dotnet publish .\installer\MimiTapSetup\MimiTapSetup.csproj -c Release -r win-x64 --self-contained false `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\dist
```

Готовый файл: `dist\MimiTapSetup.exe`. Если `publish\MimiTap.exe` отсутствует,
сборка установщика завершится ошибкой — в него нечего встраивать.

Параметры командной строки установщика: `/S` или `--silent` (тихая установка/удаление),
`/D=<путь>` (папка установки), `/NODESKTOP`, `/NOAUTOSTART`, `/NORUN`,
`/DELETEUSERDATA` (при удалении снести настройки), `--install` (принудительная установка),
`--uninstall` (удаление). `Uninstall.exe` в папке установки по умолчанию удаляет.

Автозапуск пишется в `HKCU\...\CurrentVersion\Run` как `"MimiTap.exe" --minimized`;
программа при запуске берёт это значение из реестра, поэтому галочка в настройках
всегда соответствует реальному состоянию.

Иконка: `Assets\MimiTap.ico` — многослойный `.ico` с размерами 16, 20, 24, 32, 40, 48,
64, 96, 128 и 256 px. Она же используется как значок exe, трея и установщика. Чтобы
заменить иконку, положите новый `.ico` в `Assets\MimiTap.ico` и пересоберите publish и
установщик; программа сама обновит иконку в `%AppData%\MimiTap\assets`.

## Запуск

```powershell
.\publish\MimiTap.exe              # обычный запуск
.\publish\MimiTap.exe --settings   # сразу открыть настройки
.\publish\MimiTap.exe --minimized  # запустить скрытым (используется автозапуском)
.\publish\MimiTap.exe --selftest   # самопроверка, отчёт в %AppData%\MimiTap\selftest.log
.\publish\MimiTap.exe --diag       # журнал кликов и hit-test в %AppData%\MimiTap\diag.log
```

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+M (настраивается) | показать/скрыть картинку |
| F5 | открыть настройки |
| Esc | скрыть картинку |
| ПКМ по картинке или по трею | настройки / меню |

## Замена картинок

Проще всего положить свои файлы в `%AppData%\MimiTap\assets` как `1.png` и `2.png`
(встроенные картинки при первом запуске копируются туда). Также можно выбрать любые
изображения кнопками «Выбрать...» в настройках.

## Код

| Файл | Назначение |
|---|---|
| `App.xaml(.cs)` | точка входа, единый экземпляр, тема оформления, лог ошибок |
| `AppController.cs` | трей, горячие клавиши, глобальный хук мыши, hit-test, применение настроек |
| `OverlayWindow.xaml(.cs)` | прозрачное окно поверх всех окон, альфа-маска, перетаскивание, позиция/размер |
| `SettingsWindow.xaml(.cs)` | окно настроек, закрытие в трей |
| `AppSettings.cs` | модель настроек + `SettingsStore`: чтение/запись JSON (UTF-8 BOM), распаковка ресурсов |
| `SoundService.cs` | воспроизведение звука с обрезкой до 1 с, автозапуск в Windows |
| `NativeMethods.cs` | Win32: ex-style окна, глобальный хук мыши, горячие клавиши |
| `SelfTest.cs` | режим `--selftest` |
| `installer\MimiTapSetup\Installer.cs` | логика установки/удаления, ярлыки, реестр, самоудаление |
| `installer\MimiTapSetup\MainWindow.xaml(.cs)` | интерфейс установщика (шаги установки, журнал) |
| `installer\MimiTapSetup\App.xaml(.cs)` | режимы установщика: тихий, `--delete`, определение удаления |
